# pain001-sdk-rust v0.0.89

## Highlights ⭐️

* **In lockstep with pain001 0.0.89**: the crate's second release. CI
  runs the conformance kit, the typed tests and every example against a
  live pain001 0.0.89 server.
* **Same API as 0.0.88**: no source file changed since 0.0.88, so code
  written against it builds unchanged once the requirement in
  `Cargo.toml` names 0.0.89.
* **ureq 3.5.2**: the HTTP client moves to 3.5.2 in `Cargo.lock`, the
  same version the fuzz workspace already used. The `Cargo.toml`
  requirement is unchanged.
