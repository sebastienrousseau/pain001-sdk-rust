# pain001-sdk-rust v0.0.88

## Highlights ⭐️

* **First release, on crates.io**: `pain001-sdk` 0.0.88 is a typed,
  blocking client for every endpoint of `pain001 serve`, proven against
  the suite's conformance kit in CI on Rust 1.85 and stable.
* **Opt-in retries for GET calls**: `RetryPolicy` retries `health`,
  `faces` and `GET` requests after a connection failure, a 429 or a 503,
  honouring `Retry-After`. A `POST` is never retried, so a payment file is
  never submitted twice.
* **An example and a benchmark for every method**: twelve runnable
  examples and criterion benchmarks (client-side cost and loopback round
  trips) run in CI against a live server, with lines and regions at 100%
  coverage.
