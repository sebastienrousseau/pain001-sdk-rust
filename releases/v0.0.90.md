# pain001-sdk-rust v0.0.90

## Highlights ⭐️

* **In lockstep with pain001 0.0.90**: CI runs the conformance kit, the
  typed tests and every example against a live pain001 0.0.90 server,
  which fixes a race that made a freshly started `pain001 serve` answer
  its first parallel requests with HTTP 500.
* **An API check that checks**: cargo-semver-checks now runs 229 checks
  against the newest crates.io release, held to a patch release's
  rules. Before, it skipped every check between 0.0.x versions while
  reporting success.
* **Same API as 0.0.89**: no source file changed since 0.0.89, so code
  written against it builds unchanged once the requirement in
  `Cargo.toml` names 0.0.90.
